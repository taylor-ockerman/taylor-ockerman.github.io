Unity Split-Screen PvP

Allez

A local split-screen fencing game built in Unity, focused on sharp timing, stamina management, menu flow, persistent player data, and readable two-player match balance.

  • Unity
  • C#
  • Local PvP
  • Combat
  • UI
  • Persistence
View GitHub Repo
Role Gameplay / UI Programmer
Engine Unity
Tools C#, GitHub
Source Public GitHub repository

Features

  • Fencing mechanics built around spacing, commitment, recovery, and timing windows.
  • Stamina pressure to encourage measured attacks instead of constant button mashing.
  • Menus and UI states for player feedback, round flow, and match readability.
  • Data persistence for saving and restoring player-facing game data.

Focus

  • Making split-screen player actions feel responsive while keeping combat outcomes readable.
  • Communicating player state clearly through UI and in-game feedback.
  • Balancing stamina, timing, and combat values through short test loops and practical tuning.
