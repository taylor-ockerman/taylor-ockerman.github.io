Unity Multiplayer

Allez

A multiplayer fencing game built in Unity, focused on sharp timing, stamina management, clear combat feedback, and readable player-versus-player match flow.

  • Unity
  • C#
  • Multiplayer
  • Combat
  • UI

Features

  • Fencing mechanics built around spacing, commitment, recovery, and timing windows.
  • Stamina pressure to encourage measured attacks instead of constant button mashing.
  • UI states for player feedback, round flow, and match readability.

Focus

  • Making multiplayer actions feel responsive while keeping combat outcomes readable.
  • Communicating player state clearly through UI and in-game feedback.
  • Iterating on game feel through short test loops and practical tuning.
