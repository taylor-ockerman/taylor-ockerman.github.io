Sandy Sim

A solo custom C++ engine and particle sandbox built around cellular automata, real-time rendering, UI layers, and chunk-based optimization for larger simulations.

  • C++
  • SDL3
  • ECS/OOP
  • XML

Role Solo Engine / Gameplay Programmer
Engine Custom C++ Engine
Tools C++, SDL3, GitHub
Source Public GitHub repository

Features

  • Cellular automata simulation for sand, water, fire, steam, and density interactions.
  • Chunk sleeping and update partitioning to reduce unnecessary simulation work.
  • Camera systems, UI layers, and rendering structure built into the custom engine.

Focus

  • Scaling particle counts while keeping interactions stable and readable.
  • Balancing ECS-style data flow with practical object-oriented gameplay code.
  • Debugging collision behavior and edge cases across active and sleeping chunks.
